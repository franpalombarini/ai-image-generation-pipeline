AI Image Generation Pipeline
Sistema local de generación de imágenes con IA usando ComfyUI y modelos open source.

Hardware
Ryzen 9 5900X
RTX 3060 Ti 8GB
32GB RAM
Stack
ComfyUI (portable)
Wan 2.2 I2V FP8 (video)
Ollama para LLM local
Capacidades
Generación de imágenes con workflow personalizado
Video a partir de imágenes (I2V)
Procesamiento batch con parámetros ajustables

# Levantar ComfyUI
